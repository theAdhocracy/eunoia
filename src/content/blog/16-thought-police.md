We have received a number of comments and emails recently regarding the “Your Thoughts” blog feature. It would appear that for the past few days anyone who had attempted to use said feature was instead being greeted with an error message of “Invalid Data”. We’ve been working on the issue since then and are glad to say that the fault has been located and fixed.

For anyone interested, since linking Eunoia Studios in with sites such as Jcink.com, Youtube and Viddler we’ve been having a lot more traffic from Russia which unfortunately means spam bots; we already had some pretty efficient measures in place for catching and deleting spam but some was slipping through the cracks. In an attempt to prevent this we installed a few more behind-the-scenes features which proved highly efficient at outright preventing bots from posting.

However it was one of these new features that was also conflicting with the “Your Thoughts” panel, believing it to be a back-door for spambots. The conflict has now been remedied and if any further issues do occur please feel free to contact [redacted]
