As for sustainability, as long as we have a web connection we’re fine for blogging and uploading photographs. Vlogging is reserved for free web connections where we’re staying for a while; the actual video can be shot and edited without internet and we can store it until we find somewhere to upload it but it is the most intensive so it’s use will be limited.

I think the main black hole will be in Malaysia. We can find internet connections relatively cheaply (if Borneo is anything to go by) however WiFi zones are somewhat harder to find.

Twitter thoughts of course help when we don’t have any web connection. Hopefully though, providing we have something worth blogging about, the process will be sustainable.
